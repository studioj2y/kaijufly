# KaijuFly (怪獣フライ · 特撮スタジオ見学大冒険)

> 昭和レトロ特撮映画のオープンセットを舞台にした、ワンボタン爽快キャノン弾射アクション！
> 基于经典抛物线弹射玩法（Johnny Crash 致敬），融合昭和特摄片场微缩模型美学与纯粹的一键街机操控。

---

## 🌟 游戏特色 (Game Features)

1. **纯粹一键操作 (Pure One-Button Arcade Controls)**:
   - 绝不堆砌复杂的多键动作，坚持原汁原味的极简街机魅力：
   - 第1次点击/空格：锁定大炮角度 (Angle)
   - 第2次点击/空格：锁定火药力度 (Power)
   - 飞行中长按/按住：双手扑腾滑翔 (Flap) 并消耗体力槽 (AP)；松开顺滑俯冲。

2. **特摄见学主角与幽默收尾 (Tokusatsu Studio Tour & Souvenir Snapshots)**:
   - 告别残忍的“粉身碎骨”，化身为兴奋参观特摄片场的小朋友（飞行眼镜、红色小马甲）。
   - 每次落地生成略显狼狈却无比欢乐的 **「見学記念写真」**（拍立得拍下的高光瞬间）与 **「特撮スタジオ日報」**。

3. **绝地借力与空气动力学优化 (Aerodynamics & Ground Rebounds)**:
   - **扑腾前推力 (Flap Propulsion)**：长按扑腾不仅提供升力，还会主动向前推进加速；体力耗尽后具有微弱挣扎保底，挣扎真正可以改变结局！
   - **俯冲动能转化 (Aerodynamic Swoop)**：向下俯冲滑翔能将势能转化为高额前进速度，贴地高速掠过！
   - **特摄受身滑铲 (Skid & Rebound)**：高速触地触发滑行打水漂与火花弹跳，绝不突兀猝死暴毙！
   - **高密度地面交互设施 (Ground Boosters)**：皮套大肚腩弹簧床、昭和纸板大楼爆碎弹射、原子地井蒸汽冲天、剧组高级便当体力补满、摄影滑轨极速冲刺！

4. **双巨鸟怪兽分工 (Rodan vs. Mothra)**:
   - **空の大怪獣 ラドン (Rodan)**: 钢丝威亚拉扯，触发超音速破音障喷射加速 (`Sonic Boom`)，向前狂飙拖拽。
   - **巨蛾怪獣 モスラ (Mothra)**: 振翅伴随七彩光粉洒落，温柔托举升空并**极速补满主角体力槽**！

5. **多幕动态片场演化与中后期高密度 (Dynamic Stages & Density)**:
   - **第1幕（0 ~ 1200m）**：白昼摄影棚 · 郊外微缩山峦
   - **第2幕（1200 ~ 2500m）**：夕陽の怪獣大決戦 · 赤红落日与激战暮色
   - **第3幕（2500 ~ 4200m）**：深夜の東京ミニチュア · 霓虹夜景与扫射探照灯
   - **最终幕（4200m+）**：宇宙月面特撮 · 低重力轻盈漂浮与悬挂地球道具

6. **经典特摄名场面致敬 (Classic Tokusatsu References)**:
   - **基拉斯旋转 (Gillas Spin)**: 《雷欧奥特曼》第1集黑基拉斯与红基拉斯孪生怪兽抱在一起在旋转转盘上狂旋掀起的大龙卷风！
   - **安吉拉斯 (Anguirus)**: 刺甲龙怪兽的背甲尖刺不小心勾破裤子，露出滑稽红心四角内裤！
   - **手绘巨幅背景布撕裂 (Painted Canvas Tear)**: 一头撞破富士山画板，脑袋卡在破洞里傻笑，摄制组目瞪口呆！
   - **还有哥斯拉皮套橡胶肚皮弹性蹦床、超兵器防卫军喷气战机、高压特斯拉电光、摄影摇臂滑轨、导演折叠椅等丰富互动！**

## 📁 模块化代码结构 (Architecture)

```text
kaijufly/
├── index.html        # 特摄片场风格主页面、HUD仪表盘、见学纪念拍立得结算面板
├── style.css         # 昭和特摄场记板条纹、复古报纸做旧滤镜、CRT显像管质感
├── audio.js          # Web Audio API 纯合成音效（无需外部音频资产，即开即响）
├── landings.js       # 8种特摄片场见学结束搞笑插画绘制与逻辑
├── entities.js       # 主角布娃娃姿态、拉顿、摩斯拉、基拉斯兄弟、哥斯拉等微缩模型渲染
├── game.js           # 严格物理引擎（PPM=10, 重力/空气阻力/体力衰减）、无限地图生成与任务系统
└── README.md
```

## 🚀 启动运行 (How to Play)

由于游戏采用纯原生 Canvas 2D + Web Audio API 编写，无任何第三方重量级依赖：
- 直接在浏览器中双击打开 `index.html`，或者通过任意本地静态 HTTP 服务器打开（如 `Live Server`、`python -m http.server 8000` 等）。
- 手机端与桌面端均适配，支持点击屏幕 / 空格键操作。
