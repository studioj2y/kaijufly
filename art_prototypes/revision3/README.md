# 动作与抓握修订

本轮三组修改：旋风／怪兽细节，主角表情／起播／抠图，带飞抓握／遮挡。继续使用已授权的 Image API CLI（gpt-image-2），最终提示词保存在本目录五个 `*-prompt.txt`，原始七格动作图为 `*-source.png`。摩斯拉沿用上一轮源图并重新处理透明边缘。

- 吉拉斯：增加全身旋风、突出的背部大角；七个视角按同一方向排列，第三帧为黑吉拉斯背面，第六帧为红吉拉斯背面，中间包含侧背面。两只始终相抱。
- 男女主角：改为闭口浅笑，随动作轻微变化，保持衣帽与角色身份。
- 挥臂：每次新按下独立重置动画时钟，从明显抬臂的第六张姿态开始，再循环经过其余六张；避免全局时钟恰好落在类似滑翔姿态时造成迟滞。持续按住不反复重置。
- 拉顿：七帧都增加向下伸出的双腿与爪趾。
- 带飞：按爪尖重新登记拉顿和摩斯拉每帧的位置，使翼拍不改变抓握点。对齐主角肩背；先画怪兽，再画主角，重叠区主角在前。携带时主角使用稳定姿态。
- 引力射线：金色分叉从乌云内部伸到云外，七帧内充能、释放、淡出。
- 清理：旧帧审计在 34 张图中检测到不同数量的洋红色背景残留。更严格去除背景、保留半透明旋风与光线、清零透明像素 RGB，并导出无损 WebP。42 张新帧全部通过透明边框与残色检查，见 `alpha-audit.json`。
