# 高空分布与动画修订

本轮按三组修订同步：主角透明素材清理；无限高度与分层分布；怪兽和光效重绘。

## 美术与动画

- 男主角：旧 WebP 导出后在完全透明区写入了预测颜色，出现横向色块风险；另外第 3 格混入相邻角色的鞋尖。现在清除透明像素 RGB、移除与角色断开的碎片并保存为 PNG。男女主角、摩斯拉、拉顿一并换用干净 PNG，既有抓握点和表情不变。`boy-cleanup.png` 展示全部七帧在深浅底色上的结果。
- 引力射线云：顶部及云层中部两侧均增加向外放射的金色电弧，保留少量向下分支。七帧为充能、放射、衰减循环。
- 加美拉：替换空中的“哥斯拉肚腩弹跳”，新名称“加美拉旋转飞行”。四肢、头和尾收入甲壳，四个开口喷蓝焰。最终使用 `gamera-master.png` 的同一副甲壳，按一圈七等份旋转并压缩透视，避免不同生成帧的甲壳变形或仅来回摇摆。保留向上托举的互动作用。
- 吉拉斯：保留相抱、长背角、背面及侧背面帧；风带加厚，并加入环绕全身的细小蓝色电弧。
- 哥斯拉：地面原子吐息机关换为《怪兽之王》仰天吐息姿势，七帧表现背棘发亮、吐息增强和衰减；脚底固定在地面。
- 以上均为七帧、7fps；使用既有特摄质感与水墨漫画笔触。

继续使用用户已授权的 Image API CLI，模型 `gpt-image-2`。本目录 `*-prompt.txt` 保存完整提示词，`*-source.png` 保存生成源图；加美拉的第二次定向修订为 `gamera-master-prompt.txt` / `gamera-master.png`。`build.py` 处理透明边缘、色溢、碎片和连续旋转，再导出游戏实际读取的 56 张 PNG。脚本对**保存后重新解码**的文件检查透明区 RGB、残色及边框，结果见 `alpha-audit.json`。

## 高度分布

| 高度 | 较常出现的道具 | 说明 |
| --- | --- | --- |
| 30 米以下 | 少量空中道具 | 每区段基础 8% 概率出现 1 个；地面机关单独生成 |
| 30–80 米 | 摩斯拉 | 权重占比约 39% |
| 80–130 米 | 飞机 | 权重占比约 38% |
| 130–180 米 | 拉顿 | 权重占比约 38% |
| 180–230 米 | 引力射线云 | 权重占比约 41% |
| 230 米以上 | 沿用第四层 | 每 50 米继续生成，密度不随高度递减，无硬上限 |

每层所有八种空中道具都有非零概率。吉拉斯和哥斯拉吐息保持地面定位。世界按横向区段和垂直层格分别生成，已生成横向区段也能在玩家爬升时补上新的高度层；种子由区段和高度决定，不随访问顺序改变，重复经过不刷新已用道具。飞过的旧区段及生成记录一起回收。

各层允许空区段，基础空中生成预算为原区段预算的 35%，防止扩展高度后补给形成自动续航链；密度解锁仍生效。低空另外降低概率。在 12 个固定种子的基础配置试跑中，持续按住也全部自然结束，中位距离约 2735 米，最长 98 秒；满解锁配置保留长距离刷分能力。

## 验证

- `distribution-check.js`：12 万次抽样，四层优势类型及各类型混合概率；验证 105、305、1005、10005 米等实际世界生成和碰撞触发；重复访问不增生、保留已消耗状态；10 万米前进后对象及生成记录保持有限。
- 120 个种子比较低空与第一层密度；24 次完全不操作飞行均正常结束，最长 20 秒。
- `animation-check.cjs`：56 张图片及七帧循环、挥臂起播、28 种带飞组合的遮挡次序、逐帧实机截图和千米高空显示。图片加载合并重复首帧、限制并行读取，失败时重新请求一次；测试主动中断一张帧图验证恢复。
- `browser-check.cjs`：角色选择、实际发射和结算、解锁保存、手机布局及浏览器错误检查。
