# 平成造型与见学纪念画廊

## 本轮素材

- 哥斯拉：开场立绘、仰天吐息七帧、男女合影统一为 1991–1994 年间的平成皮套方向；较短的猫科感嘴部、厚重下肢、颗粒皮肤和浅色枫叶状背鳍。保留向上喷吐的动作，脚底重新定位接地。
- 安吉拉斯：开场、向右慢走七帧、男女骑行结局十四帧都增加长而密的象牙色背刺。结局源图第二次修订补全尾巴，保留完整裤装与骑行。
- 加美拉：参考平成三部曲实拍飞行模型，重画有磨损和不规则层叠甲片的甲壳。四肢缩壳、蓝色喷焰、水平偏航旋转，七帧 7fps，不在画面平面纵向翻滚。
- 奥特曼彩色计时器：蓝色发光凸面、银色边框与红银底座，七帧脉动；游戏标签、反馈文字与备用绘制一并替换。
- 15 类互动 × 两位主角，新绘 30 幅完整环境合影。原有八类结局 × 两位主角，导出 16 幅有背景的结局照片。所有照片均为 768×768 JPEG。

`art-preview.jpg` 为怪兽/道具预览，`animation-preview.gif` 为七帧循环，`souvenir-preview.jpg` 为互动合影总览。`opening-*.png`、`*-frame-*.png`、`ending-anguirus-*.png` 和 `*-photo-*.jpg` / `photo-*.jpg` 为项目直接使用的成品。

## 生成与导出

沿用用户已授权的 OpenAI Image API，使用 bundled imagegen CLI 的 `edit` 模式，模型 `gpt-image-2`，质量 `high`。本轮共 27 次调用：23 个初始绘制任务、一次安吉拉斯尾部修订，以及三次道具合影背景清理。没有更换模型。

全部完整提示词保存在 `*-prompt.txt`；`jobs.json` 记录初始 23 项的参考输入和尺寸，`prepare.py` 保存提示词和参考拼版制作过程；额外修订使用 `ending-anguirus-repair-prompt.txt`、`photo-background-repair-prompt.txt`（便当、纸板大楼、摄影滑轨三组）。原始结果保存在 `*-source.png`，经检查后 `build.py` 去除纯品红背景、对齐中心或脚底、导出七帧 PNG，透明像素 RGB 清零。照片分别从双人分栏原图中裁出男女独立画面；结局照片由既有绘画和背景合成。未采用的初稿源图保留以供制作追溯，实际导出优先采用 `*-repair-source.png`。

## 互动与收藏规则

每局的首次同类互动才进入拍照：1.2 秒动态互动、0.2 秒快门闪光、随后显示新绘的纪念照；总计约 3.6 秒，1.6 秒起可点“继续见学”或空格/回车提前返回。初次读取照片最多额外等 1.2 秒，失败仍可继续，收藏记录保留。画廊可随时从主菜单和结算页面打开。

拍照状态独立推进演出时钟，暂停位置、速度、体力、连击、带飞、旋风、特效和镜头计时；结束时保留碰撞已经产生的增益，清除长按状态，重新按住即可挥臂。每局的重复接触照常结算互动效果，不再次弹出照片；新一局可以再次拍摄，永久收藏不重复计数、不增加经济奖励。

收藏按互动/结局、类型、性别标识，保存首次拍摄距离和日期，使用独立键 `kaijufly_album_v1`。旧工坊存档不迁移、不改写。损坏存档忽略无效条目，保存失败时保持当前内存收藏并提示。这里的“永久”指当前浏览器本地保存，清除站点数据或更换浏览器不会自动带走照片。

- `progression-check.js`：经济系统及 72 次确定性飞行，基础难度与解锁后持续刷分行为保留。
- `interaction-check.js` 与 `distribution-check.js`：两圈旋风、行走避让和各高度道具分布。
- `opening-check.cjs`：开场三阶段、手动跳过和七帧吐息脚底。
