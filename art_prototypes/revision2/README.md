# 第二轮角色与动画修订

本轮分三组交付：角色与朝向、七帧动作与效果、高度分布。使用用户授权的 Image API CLI（gpt-image-2）生成，最终提示词为本目录六个 `*-prompt.txt`；原始七姿态图为 `*-source.png`。`build.py` 提取 42 张透明 WebP 帧，并镜像原有飞机为向右飞行。

- 男主角：原服装与角色基础，红色棒球帽，开心表情。
- 女主角：同一画风与服装体系，风镜、短马尾，开心表情。
- 两位主角上下挥臂，肩膀、胸背和双腿随发力变化；新开页面先选择角色，主菜单可更换，能力与成长共用。
- 摩斯拉、拉顿始终面向右方，包括被它们携带时与菜单装饰。
- 吉拉斯：两只怪兽面对面相抱，围绕竖直轴旋转，脚下产生紧凑旋风；同步缩小原先过高的碰撞范围。
- 引力射线：暗色云团内的金色闪电，由暗到亮再淡出，取代原有铜球蓝色电光。

每组 7 帧，运行时按 7fps 播放，1 秒一循环。共同裁切区域保持尺度一致。附加的轻微漂移仍连续计算。`animation-preview.gif` 用于预览，GIF 时间精度为 10ms，游戏计时精度不受它限制。

动作参考：[Johnny Crash 的鸟式挥臂描述](https://www.pocketgamer.com/johnny-crash/review/)；[圆谷官方黑吉拉斯与红吉拉斯资料](https://tsuburaya-prod.com/encyclopedia/black-giras-and-red-giras)。相抱姿态按用户明确要求绘制；并未声称逐帧复刻原作录像。

## 高度分布

先随机决定高度带，再按该高度的权重选择互动，随机性保留。50,000 次固定随机抽样：

| 高度 | 最常见互动 | 该带中约占比 |
|---|---|---:|
| 低空 14–32m | 摩斯拉 | 43% |
| 中空 32–55m | 飞机 | 48% |
| 高空 55–80m | 拉顿 | 54% |
| 云端 80–115m | 引力射线 | 72% |

吉拉斯与蒸汽设施是贴地物件，高度固定在 9m，不随自由飞行物件漂到高空。原有密度升级仍控制数量，不改变高度逻辑。

## 检查

浏览器实测两种主角选择、刷新保存、角色切换、七张不同动画帧、实际起飞、工坊购买与关闭、四幕与手机布局，无运行错误。测试档案与用户存档隔离。

72 次固定种子玩法模拟中，新手和满级的无操作样本各 12 次均结束。满级低空自动策略有 10/12 次超过 600 秒观察窗口，低空摩斯拉的集中出现提高了长局续航；这仍是后续真实试玩要观察的平衡点，不代表无限飞行已被证明。
