本轮完成三组主体改动（怪兽重绘、场景与分布、碰撞收场），并加入随后提出的独立选角立绘与随机怪兽开场。源图、提示词、制作脚本和游戏输出一起保存。

## 选角与开场

- `portrait-boy.png` / `portrait-girl.png` 是重新绘制的半身立绘，保留红色棒球帽男孩与风镜女孩的服装和身份，表情为兴奋、好奇的小幅微笑。没有拿游戏飞行帧裁切放大。

- 七种随机登场：摩斯拉、拉顿、加美拉、哥斯拉、吉拉斯兄弟、王者基多拉、安吉拉斯。每一种都有独立绘制的 `opening-*.png` 大幅怪兽插画。
- 选角后先展示空场景 0.6 秒；主角在 0.6–1.6 秒从左侧滑入，怪兽在 1.15–2.2 秒从右侧滑入；2.8 秒出现菜单。人物位于怪兽图层前方，所有位置适配横屏及竖屏。

## 怪兽与场景

- 加美拉根据用户给的模型照片改为隆起的长椭圆、叠片甲壳，四周弯曲的青蓝色喷焰；七个旋转帧保留甲壳体积，不再压成扁圆盘。
- 引力射线云扩大为 32×26 米的视觉范围，顶部与中部两侧有多次折弯、分叉的大型金色电弧。充能判定保留在云团内部，装饰光弧不会额外形成自动补给链。
- 哥斯拉仰天吐息扩大为 25×44 米的视觉范围，身体、吐息宽度及长度一同提高。
- 三组 `ground-strip-*.png` 绘制仓库模型、备用景片、工具、摄影机、支架与电缆，按种子混合循环，每组三段均使用三个不同素材。透明边缘交叠衔接，地面覆盖到屏幕底部。
- 四幕各有天空、远景、近景三层，按不同世界位移比例与缓慢时间漂移循环。高空及长距离不再把背景滚动钳制在最后一帧。夜景白色分隔线和其他生成画稿不等宽的分层边界已逐一裁除。
- 生成道具时检查整个可视占用范围；不同类型至少横向 9 米或纵向 5 米，同类至少横向 20 米或纵向 12 米。包含飞行动画的翼展。找不到空位时留空，不堆叠。

## 八种收场

每种收场都有男孩、女孩两组七帧，7fps 播放后保留纪念画面，约 2.9 秒进入结果页。场景中的道具来自动画的完整首帧，碰撞前不会先画成破损状态。

| 道具 | 收场过程 |
| --- | --- |
| 幕布 | 完整幕布 → 鼓起 → 撞破 → 头伸出来 → 不好意思地笑、挥手 |
| 安吉拉斯 | 接近背甲 → 落坐 → 扶稳 → 害羞挥手 |
| 沙盘 | 落入沙坑 → 扬尘 → 靴子朝天 → 起身抖沙 |
| 铁塔 | 碰撞模型 → 塔架弯折 → 坐稳、比耶 |
| 奥特战士 | 喝奶茶 → 接住主角 → 两人对视、笑着合影 |
| 水槽 | 完整水槽 → 落水 → 水花 → 探头、顶着小潜艇 |
| 摄影轨道车 | 接近摄影机 → 落上座位 → 扶住摇把、挥手 |
| 导演椅 | 碰上椅子 → 椅架折倒 → 分镜纸飘起 → 坐在纸堆中微笑 |

使用两帧之间的运动路径检测接触，解决高速穿过整个道具却漏判的问题。优先触发路径上最先接触的结束道具，结束带飞与惯性；普通增益设施保留原有互动。碰撞插画等待自身素材加载后开始计时，下载失败有有界回退，不会卡住结算。

## 制作方式

使用用户已授权的 Image API，模型 `gpt-image-2`，高质量生成。`*-prompt.txt` 保存完整提示词，`*-source.png` 保存原始生成画稿。参考输入是用户提供的加美拉模型、基多拉海报与开场构图，以及项目内既有角色、场景素材。外部参考原图不重复提交。

`prepare.py` 和 `prepare_opening.py` 准备提示词；`build.py` 分帧、按实际图稿边界分层、清除品红底色、处理光效半透明、登记共同基线、导出 PNG。所有 **167 张 RGBA 输出**均保存后重新解码，确认完全透明区域 RGB 为零，记录于 `alpha-audit.json`。背景使用 JPEG；`manifest.js` 保存道具实际宽高比例，供绘制与碰撞共用。

运行示例（环境需有已配置的 API key，命令不打印密钥）：

```powershell
python image_gen.py edit --image reference-opening.png --prompt-file opening-moth-prompt.txt --model gpt-image-2 --quality high --size 1536x1024 --out opening-moth-source.png
python art_prototypes/revision5/build.py
```

## 验证

- `scene-check.js`：384 个世界快照、216 万余对道具间距；八种收场 × 两种角色的高速碰撞、先后顺序、上方擦过、带飞中接触、结算及奖励只记一次。
- `distribution-check.js`：12 万次高度分布抽样，实际生成至 10005 米；120 个种子的低空密度、旧道具回收；24 次完全不操作均结束，最长 19 秒。
- `progression-check.js`：解锁、保存和能力档位；72 次飞行模拟。基础配置持续按住的 12 个固定种子全部结束，最长 90 秒，中位距离约 2931 米；满解锁在 180 秒观察窗口仍可长距离刷分。这是抽样结果，不代表所有随机局面的保证。
- `revision5-check.cjs`：全部新素材加载、左右入场顺序、七种怪兽组合、48 个收场动画状态、三层高空漂移、桌面和手机布局。
- `browser-check.cjs` / `animation-check.cjs`：原有实际游玩、工坊、存档、七帧循环、带飞遮挡和中断图片重试的回归检查。
